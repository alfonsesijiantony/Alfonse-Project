# Contributing to the Python Student Project

Thank you for contributing to this project!

## 1. How to Report an Issue

1. Describe the problem clearly.
2. Explain what you expected to happen.
3. Explain what actually happened.
4. Provide steps to reproduce the problem.
5. Give the issue a clear title.

## 2. How to Suggest a Feature

1. Describe the feature you want to add.
2. Explain why the feature would be useful.
3. Explain how the feature could work.
4. Keep your suggestion simple and clear.

## 3. How to Create a Branch

Create a new branch before making changes.

Example:

```text
feature/add-student-grades
```

Use a branch name that clearly describes your changes.

## 4. How to Make Changes

1. Make the required changes.
2. Keep the code simple and readable.
3. Use meaningful variable and function names.
4. Follow the existing project structure.
5. Check your changes for errors.

## 5. How to Test Changes

1. Run the project.
2. Check that the changes work correctly.
3. Test different inputs when appropriate.
4. Make sure existing features still work.
5. Fix any errors you find.

## 6. How to Create a Pull Request

1. Review your changes.
2. Test your changes.
3. Create a pull request from your branch.
4. Give the pull request a clear title.
5. Explain what you changed.
6. Mention the testing you performed.
7. Wait for the changes to be reviewed.

## 7. Basic Coding Guidelines

- Write clear and readable Python code.
- Use meaningful names for variables and functions.
- Keep functions simple.
- Use consistent indentation.
- Avoid unnecessary code.
- Add comments when they are helpful.
- Keep changes related to the task.
- Check your code for errors before submitting.

## Thank You

Thank you for contributing to this student project!
